How this works

The network is a scikit-learn MLPClassifier with one hidden layer of 32 ReLU neurons, trained on the classic 8×8 handwritten digits dataset. After training, every weight and bias was exported as JSON and embedded directly in this page — there's no server and no API call. Your drawing is downsampled to an 8×8 grid, normalized, and pushed through the exact same matrix multiplications the trained network learned.
